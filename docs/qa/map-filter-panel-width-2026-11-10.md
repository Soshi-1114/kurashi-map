# 地図の絞り込み一覧・設定パネル幅の修正確認

## 対象と原因

- 最新main `d7f3712` から専用worktreeで作業。元の作業ツリーの未コミット変更は保持。
- 指定プレビュー `https://kurashi-3o8i6do5s-soshi-1114s-projects.vercel.app/map?code=40100&rentMax=50000` にてPC表示で「一覧を見る」を操作し、設定パネルが画面左端まで拡張することを再現。
- `.map-layers` が幅未指定のabsolute/flexコンテナで、`.layers-panel` もmin-widthのみだったため、折り返し一覧の内在幅に応じて親子が拡張していた。

## 修正

`app/globals.css` のPC幅（769px以上）のみ変更。

- 設定ラッパーの幅を最大424pxに固定し、地図の左右14pxを除いた幅まで縮小可能にする。
- 自治体詳細の表示中は、既存の右位置410pxと左余白14pxを差し引いた空き幅まで縮小する。
- 設定パネルはラッパー幅100%、min-width: 0とし、一覧による拡張を防ぐ。
- 狭いPC幅では設定項目のラベルと選択肢を行単位で折り返す。
- 一覧の既存flex-wrap・スクロール・選択処理、モバイルシートのCSSは維持。

## Chromeでの確認

ローカルの修正後 `/map?code=40100&rentMax=50000` を使用。通常のPC幅とDevToolsのレスポンシブ表示で確認。

| 条件 | 結果 |
| --- | --- |
| PC（通常ウインドウ、約1470px幅） | 詳細表示中に一覧を開いても設定幅が拡張せず、自治体チップがパネル内で折り返す |
| PC・一覧操作 | 一覧内を縦スクロールし、埼玉県・千葉県などの結果を表示。下関市を選択して詳細が切り替わることを確認 |
| PC・詳細開閉 | 詳細を閉じた状態でも一覧を維持し、一覧からの選択で詳細を再表示 |
| 狭いPC（769px幅） | 詳細表示中の設定パネル幅345px。設定パネルはclientWidth/scrollWidthとも343px、一覧はとも315pxで横はみ出しなし。一覧を閉じる操作も正常 |
| モバイル（393px幅） | 設定シート内で一覧を開き、折り返し・縦スクロールを確認。行田市を選択するとシートが閉じて詳細が開く。設定シートの再開閉も正常 |
