# 外国人住民・教育環境の独立ランキング

## 初回の対象

新規4URLのみを収益評価の対象とする。既存ページは関連リンクのみ追加し、広告・集計・順位・SEO設定を変更しない。

| パス | 地域単位 | 指標 |
| --- | --- | --- |
| /ranking/foreign-resident-growth | 市区町村 | 前年比増加数 |
| /ranking/foreign-resident-growth-rate | 市区町村 | 前年比増加率 |
| /ranking/foreign-student-elementary-ratio | 都道府県 | 小学校の外国籍児童割合 |
| /ranking/foreign-student-junior-ratio | 都道府県 | 中学校の外国籍生徒割合 |

固定ルートが既存の `[metric]` とは別のサーバーコンポーネントを使用する。既存 `RANKINGS` と `Municipality` の契約は変更しない。データは `public/foreign-resident-issues/dataset.json`、出典はその `sources` を参照。新規4ページの定義は `lib/foreignRankings.ts` に集約する。

住民は2026年1月1日と2025年1月1日の同一コードを比較する。政令市は親市、東京特別区は区。最新年の対象外6自治体を除く。欠損は補間しない。増加率は前年0人では算出しない。小中学校は2025年5月1日、学校所在地別・国公私立計で分母をそろえる。日本語指導の必要人数を外国籍在籍人数へ流用しない。

住民上位100件、教育47件を初期HTMLに掲載。検索は全地域が対象で、全国順位を維持する。同値は同順位（1, 1, 3形式）。丸める前の値で並べ替える。地図リンクにはテーマ・年度・指標・学校種・地域コードを渡す。年度更新は専用データ生成スクリプトを実行したうえで、出典・対象年度と画面を確認してビルドする。

## 広告

既存の `DisplayAd`、ランキング用広告ユニットと配信条件を再利用する。新規ページは各1枠、SPは先頭10件の後、1200px以上は同じ1枠を上位表の横に配置する。有効データ10件未満では設置しない。地図は0枠。

検索中・検索結果0件には広告を表示しない。検索を解除しても同じ文書では広告を再生成しない。広告停止時に空の横欄を確保しない。最低250pxの既存予約領域、広告ラベル、Googleが選ぶレスポンシブサイズを維持する。

実配信は既存のProduction・正規ホスト・HTTPSの条件に従う。この実装で本番設定やAdSense管理画面を変更しない。ローカル・Previewでは、既存の有効フラグ・公開ID・ランキング枠IDを設定してもダミー枠だけとなる。既存枠IDは `mobile-full-width-2026-11-16.md` を参照。

## 計測と公開後の評価

- GA4の通常page_viewをURLで集計し、新規4URLだけの閲覧数を抽出する。`new_ranking_view` は `feature_id=foreign-resident-issues`、`metric_key`、`geography`、`entry_type` を送る。入口は同一オリジンのreferrerからranking/new_map/other_internalに分類し、それ以外はexternal_or_directとする。
- 表が実際に画面へ入った際に `new_ranking_table_view` を文書内で1回送る。新規ランキング・新規地図へのクリックは `new_feature_navigation` と destination/target_path を送る。自由入力の検索語、外部referrer URL、広告クリックは送らない。
- GSCは4URLを個別・住民2URL・教育2URLで集計し、表示回数、クリック、検索語、インデックス状況を確認する。
- AdSenseは新規4URLのURLチャネルまたはページ別レポートで、推定収益・PV・ページRPM・視認性を確認する。GA4連携が未設定なら、AdSenseの収益とGA4の閲覧を別々に報告する。既存ユニットを共用するためユニット全体の収益を新機能の収益にしない。
- 公開7日後に配信・エラー・広告表示ずれ、28日後に流入・収益・回遊を確認する。少量データなら56日まで観測し、データ不足を効果なしと断定しない。CLSはp75で0.1以下を目標にする。
- 月間見込みは `新規ページPV / 1000 × 実測ページRPM`。検索クリックとPVを混同せず、PV/RPMが未取得の間は金額を予測しない。

次の候補は5年・10年の住民増減、日本語指導・支援状況。28日間の検索語・クリック、出典の充足度を確認して採否を記録する。教育の地域別ページと年度別URLは初回には生成しない。
