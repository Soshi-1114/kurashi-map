# 既存火災保険導線の改善（2026-10-24）

## 基準と確認

利用者共有の今月A8集計: 3,528インプレッション・8クリック・CTR約0.227%。A8ホーム画面でも同値を読み取り確認。ASP表示回数は画面内視認・利用者数ではない。

GA4 Data APIの確定遅延を避けた10/15〜10/21では、火災保険の視認イベント354件・クリック0件。内訳はarea 323、pref-hazard 24、map-panel 4、shindan 3。9/24〜10/21は1,668視認・3クリック。ASPの当月集計とは期間・指標が異なるため直接比較しない。PR #237の視認判定修正前のデータであることにも注意。

A8の参加中プログラムと案件詳細を読み取り確認した。既存案件は保険スクエアbang！火災保険。賃貸や更新など別導線の申込みを成果前提の訴求にしない。管理画面の非公開報酬・識別子・リンクコードは本資料に記録しない。

公開の広告主サイト https://fire.bang.co.jp/ でも、無料の見積もり・診断の依頼サービスであること、新規加入の検討者向けの案内、見積もり依頼後に提案を受ける流れを確認。即座に匿名の比較結果が出る道具として案内しない。保険料の節約保証、特定商品の推奨、参加会社・商品のランキングを追加しない。

## 変更

1. モバイルの共通広告行で、本文の`flex-basis: 220px`が縦積み時に高さとして適用される問題を修正。モバイルだけ`flex: 0 1 auto`にし、本文とボタンの余白を縮める。ボタンの折り返しも許可して狭いカード内のはみ出しを防ぐ。共有レイアウトを使うふるさと納税・支援・電気代の行にも適用。
2. 火災保険のコピーを「持ち家の火災保険を新しく検討する方へ」にし、補償内容・保険料を見積もり/診断で確認する価値を説明。ボタンは「無料で見積もり・診断を依頼」。広告であることと外部サービス名を明示。
3. `kasai_link_render`を追加し、掲載→50%視認→クリックを分離。3イベントに`measurement_version=2026-10-24`、`cta_variant=context-v1`と掲載面を付与。地図の自治体・リンク切り替え時は新しい掲載として計測。
4. リンク先・ASP計測ピクセル・rel・referrerPolicyは保持。URLにパラメータを追加しない。

今回は既存掲載場所の改善に絞る。備蓄チェックページへの広告追加、ランキングや家賃ページへの火災保険広告の拡散は行わない。

## 検証と公開後

A8リンク・画像の未加工、掲載/視認の分離、50%未満での非発火、再レンダー時の重複防止、自治体切り替えをテストする。表示確認はローカル専用のダミーリンクで行い、実ASPクリックや本番GA4送信を発生させない。

公開後はGA4で`cta_variant`をイベントスコープのカスタムディメンションとして必要に応じ登録。`placement`別に掲載・視認・クリックとユーザー数を確認。過去の未登録分や未送信イベントは復元できない。同じ期間のASPクリック・発生・確定を別途比較する。月累計の増加だけを改善効果とみなさない。

母数が少ないためA/Bに分割せず、公開日を記録して数週間観察。表示修正と文言を同時に変えるため、どちらの効果かは切り分けられない。CTR改善・成果発生は未検証。引き続き表示とクリックが乖離する場合はページ別到達率・デバイス・リンク先の成果条件に分けて調査する。
