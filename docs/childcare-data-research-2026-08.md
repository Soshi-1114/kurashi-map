# 子育て環境データ調査: 利用可能な市区町村別指標の需要×有効度分類（2026-08）

詳細ページ「子育て・生活環境」セクション拡充のための調査記録（2026-08-28実施）。
外部データソース調査（Web・実ファイル解析込み）とリポジトリ現状監査を統合し、
**需要（検索需要・ユーザー価値・差別化）× 有効度（市区町村別網羅・機械可読・鮮度・honesty適合）**で分類する。

前提の制約: 全1,918区分（市区町村＋政令市の区）に近い網羅率で市区町村別の**公表実数**が
機械可読形式で取れるものだけが使える。推計値は不可（honesty方針）。治安・犯罪データは方針外。

現状の子育てデータ: `waitlistChildren`（CFA待機児童、2025-04-01時点）と
`amenities.preschools`（reinfolib XKT007 施設数）の2つのみ。総合スコアの childcare 軸は
待機児童の単変数。

## S: 最優先で実装（需要高 × 有効度◎）

### S-1. 保活余力（保育所等の定員・利用児童数・隠れ待機）

- **出典**: こども家庭庁「保育所等関連状況取りまとめ」別添「（参考）定員・申込者の状況」Excel。
  **既存の待機児童と同一の年次公表物**（別シート）で、パイプラインをほぼ流用できる。
- **鮮度**: 毎年4/1時点・8月末公表。**令和8年4月1日版が 2026-08-26 に公表済み**（実装の好機）。
  市区町村別Excelは令和6年版から存在（それ以前は集計表のみ。R6は公表遅延の前例あり）。
- **内容**: 定員（施設類型7区分×年齢区分: 合計/0歳/1,2歳/3歳以上）、申込者数、類型別利用児童数、
  待機児童数＋**隠れ待機3類型**（育児休業中・特定園のみ希望・求職活動休止）×年齢区分。
- **算出式（すべて公表実数の四則演算）**:
  - 定員余裕率 =（定員合計 − 利用児童数合計）÷ 定員合計
  - 年齢別余裕率（0歳児・1,2歳児）を別掲すると保活の実態に合い差別化になる
  - 隠れ待機 = 育休中＋特定園希望＋求職休止（既存の待機児童数と併記＝誠実な見せ方）
- **需要**: 「保育園 入りやすい」「(市) 保活」系。待機児童ゼロが全国9割で指標として飽和しており、
  「ゼロでも入りにくい」を可視化できる唯一の公的データ。Deep Research戦略（2026-08）でも
  IPSS将来人口の次と合意済み。
- **落とし穴**（実ファイル解析で確認済み）:
  1. **政令市は市単位のみ**（1,741市区町村）→ 既存 `isWaitlistDisclosed` と同じセンチネル・UIパターンを流用
  2. JISコード列なし → 都道府県名＋市区町村名の文字列マッチ（府中市・伊達市等は県名ペアで解決。
     fetch-waitlist.mjs が同じ処理を既に持つ）
  3. URLが毎年変わる（R8はファイル名に全角「８」とスペース入り）→ workflow env で年次手動更新
  4. 保育所等ゼロの町村は分母0 → 「保育所等なし」分岐が必要
  5. 定員に企業主導型・地方単独事業を含む列がある → 採用範囲の定義を /about に明記
  6. 広域利用（隣接市の園）は居住地側に計上されない場合がある旨の注記
  7. 代替形式: 保育提供体制ダッシュボード（Power BI）の「データテーブルZIP」に市区町村別
     構造化データあり（デジタル庁がデータ定義公開）。Excelパースと要比較
- **実装の最小変更セット**（リポジトリ監査より）:
  `lib/types.ts` に `childcare?: { capacity; enrolled; hiddenWaitlist?; source; asOf }` →
  `lib/childcare.ts`（hasChildcareData）→ `scripts/fetch-childcare.mjs`（fetch-waitlist.mjs を
  ひな型に、CFA_XLSX_URL/CFA_ASOF 流用）→ validate-data.mjs → annual workflow（Excel DL済を再利用）→
  詳細ページ kids カード＋faq.ts 1問＋ランキング（例:「保育に余裕がある市区町村」）＋
  dataFreshness → docs/data-update.md §2/§5。

### S-2. 待機児童の令和8年版への更新（付随タスク・即実行可）

現行 `CFA_ASOF="2025-04-01"`（令和7年）に対し令和8年版が公表済み。S-1と同じExcelなので、

env（CFA_XLSX_URL/CFA_ASOF）更新＋手動実行。

## A: 有効度◎で追加余地あり（需要は中）

| 指標 | 出典 | 形式 | 鮮度 | 备考 |
| --- | --- | --- | --- | --- |
| 小中学校数・児童生徒数 | 学校基本調査「市町村別集計」 | e-Stat DB/API | 毎年 | 学級数・教員数も取れる。「学区」需要の間接受け皿。幼稚園数も同ソース |
| 出生数（実数） | 人口動態統計 保管統計表（出生5-2） | e-Stat DB/API | 毎年 | 「若い世帯が増えている街」の実数根拠。※市区町村別TFRはベイズ推計のため使用不可 |
| 年少人口（0-14歳）・比率 | 国勢調査（毎年更新なら住基人口） | e-Stat API | 5年/毎年 | 比率は実行時算出（人口は保存済み）。子育て世帯の多さの直接指標 |
| 共働き世帯率 | 国勢調査 就業状態等基本集計 | e-Stat | 5年 | 「共働きで住みやすい」文脈。次回は令和7年国調（2026秋以降公表） |

いずれも e-Stat API で全国一括取得でき、既存の fetch-*.mjs（e-Stat系）のパターンに乗る。
優先度は S-1 のGSC反応を見てから（子育てカテゴリの検索需要は現状小さく=child 3クエリ/7imp、
供給を作って需要を確認する段階のため、一度に全部は作らない）。

## B: 有効度○だが工数・定義設計が必要

| 指標 | 出典 | 課題 |
| --- | --- | --- |
| 小児科・産婦人科の施設数 | 医療情報ネット（ナビイ）オープンデータ（e-Gov、施設単位CSV） | 医療施設調査の診療科別は二次医療圏止まり（API メタで確認済み）。ナビイCSVを市区町村コードで自前集計すれば可能だが、報告ベース・更新不定期・集計定義を自分で決める必要 |
| 子ども医療費助成（対象年齢・所得制限） | こども家庭庁「こどもに係る医療費の援助についての調査」（毎年・全市区町村） | **PDFのみ**。1,741件のPDF→構造化変換と転記検証のコストが高い。制度データとして差別化価値は大きく、将来候補として保留 |

## C: 使えない・見送り（判定根拠つき）

| 指標 | 判定理由 |
| --- | --- |
| 放課後児童クラブ（学童） | 市区町村別の機械可読データが存在しない（PDFのみ、e-Stat掲載「無」を確認）。全国・県集計＋上位市町村抜粋のみ |
| 合計特殊出生率（市区町村別） | ベイズ推定（5年ごと）＝推計値のため honesty 方針で不可。出生数実数（A）で代替 |
| 都市公園数・面積 | 国交省DBが令和2年度末で更新停止（R03以降のURL 404確認）。国土数値情報P13も古い |
| 保育所定員（社会福祉施設等調査） | 定員は中核市まで。市区町村別は施設数のみ → S-1 のCFAが一択 |
| 児童手当上乗せ・保育料軽減等の自治体独自制度 | 全国横断の構造化データが存在しない（民間の手集めのみ） |
| ここdeサーチ（施設単位の保育所情報） | 一括オープンデータCSVなし。スクレイピング前提のため見送り |
