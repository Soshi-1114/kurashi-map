## 自治体詳細ページのサンプル監査（2026-09-24着手）

`no-impression-pages.csv` の自治体詳細URLから、47都道府県を含む100件を固定順で抽出し、県slug・自治体コード・自治体名・データファイルの対応を確認した。100件すべてで不整合はなく、人口・家賃・在留外国人データのフィールド欠落もなかった。これは「未登録」判定そのものを検証するものではなく、GSCに現れないURLが現行データやルーティングと不一致でないかを確認する監査である。

併せて `npm run build` を実行し、自治体詳細1,918ページを含む3,149ページの静的生成が完了した。京都市・足立区・五霞町・福岡市の生成HTMLでも、title・description・canonical・H1は各1件、canonicalは現行の `/area/{pref}/{code}` に一致した。内部の自治体リンクは各ページ20〜34件あり、技術的なcanonical欠落やページ生成失敗は今回のサンプルでは見つからなかった。
