# 診療科別医療機関数（小児科・産婦人科）データ調査 — 2026-08

市区町村別×診療科別（小児科・産婦人科/産科）の医療機関数を収録できるかの実データ調査記録。
2026-08-29 実施。実ZIPをダウンロードしてスキーマとPoC集計まで検証済み。

## 結論: **可**（次ラウンドで実装候補）

医療情報ネット（医療機能情報提供制度）のオープンデータから、市区町村別×診療科別の
施設数を機械的に集計できる。ジョイン欠損ゼロ・地理コード欠損ゼロを実データで確認。

## 出典

- データセット: e-Gov データポータル「医療情報ネットのオープンデータ」（厚労省）
  https://data.e-gov.go.jp/data/dataset/iryou_teikyouseido_mhlw
- 検証に使った版: 2025-12-01 時点 ZIP（27.5MB、展開後 360MB・8ファイル）
- 更新頻度: **年2回（6月1日・12月1日時点）**。2024-08 から4リリース分蓄積

## スキーマ（実確認済み）

ZIP内: 病院/診療所/歯科 それぞれに `*-1_facility_info`（施設マスタ）と
`*-2_speciality_hours`（診療科×診療時間）、ほか助産所・薬局。UTF-8 BOM付きCSV。

**facility_info（1行=1施設）** — 病院 7,640件・診療所 76,988件（2025-12版）
- `ID`（13桁施設ID）・`正式名称`・`機関区分`（1=病院, 2=診療所）
- `都道府県コード`（2桁）＋`市区町村コード`（3桁）→ **連結で JIS 5桁**（例 01+101=札幌市中央区）。
  **政令市は区単位**・全行3桁固定・欠損ゼロ
- 所在地・緯度経度列もあり

**speciality_hours（施設ID×診療科目×時間帯1〜3の縦持ち）**
- `ID`, `診療科目コード`, `診療科目名`, `診療時間帯`(1/2/3), 曜日別開始・終了時刻
- 科目コードは体系的: **小児科=03001**（03xxx=小児系）、**産婦人科=04001・産科=04002**、
  婦人科=04003、産婦人科(生殖医療)=04004。コード表はZIP非同梱だがコード＋名称の両方が
  行に入っているため実質不要

## 加工手順（実装時）

1. facility_info（病院+診療所）から `ID → 都道府県+市区町村コード` マップを作成
2. speciality_hours 2ファイルを走査し、対象コード（03001 / 04001+04002）の行から
   `(ID, 科目コード)` を**重複排除**（時間帯1〜3で同一科目が最大3行重複する）
3. JIS 5桁で施設数をカウント → `Municipality` の新フィールドへ

PoC集計（2025-12版・妥当性の傍証）: 全国 小児科あり 17,394施設・産婦人科/産科あり
3,616施設・該当自治体1,651。世田谷区 小児48/産婦27、さいたま市西区 産婦0 —
医療施設調査の桁感と整合。

## 落とし穴・設計判断が必要な点

- **時間帯による行重複** — `(ID, 診療科目コード)` での dedupe が必須
- **URLが毎リリース変わる**（リソースごとにUUID付きURL採番。e-Stat のようなAPI安定性はない）
  → versions.mjs に手動URL更新（CFA Excel と同運用）
- 婦人科(04003)を含めるか要方針決定（含めると分娩非対応の婦人科クリニックが混入。
  「産婦人科・産科」= 04001+04002 に限定する案を推奨）
- 03991 等の複合コードが少数存在（小児循環器内科等の一括コード）。厳密には 03001 のみ、
  広義なら 03xxx 群 — 定義を注記で明示すれば honesty 方針と両立
- **出典は医療機関の自己報告ベース（G-MIS）**。悉皆調査の医療施設調査（既存
  `fetch-medical.mjs` の amenities.medicalFacilities）とは別系統で件数が数%ズレうる
  → 実装時は「出典が異なる」ことを UI/docs に明記し、総数の置き換えはしない
- 歯科・助産所・薬局も同形式で取得可能（助産所は産科系指標の補完候補）

## 実装の位置づけ

企画調査（2026-08-29 松竹梅レポート）の竹1。「小児科が多い街」の市区町村別データは
目立つ競合がなく、子育てセクション（待機児童・保活余力）と束ねると「子育てで選ぶ」
文脈が完成する。着手判断は保活余力（PR#173/174）のGSC反応（2026-09-11以降の
gsc:analyze）を見てから。
