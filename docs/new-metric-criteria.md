# 新データ軸・新ページ種別の採用基準

事業レビュー2026-09（§18 P0 / §19 TOP1「測って、捨てる」）で決めた、新しい指標軸や
ランキング等のページ種別を**足す前に**通す基準。成長エンジン（RankingDef 1定義 →
全国＋47県のページ生成）は反復コストが低いぶん、弱い軸にも機械的に適用されて
在庫が薄まる実害が出ている（駅数・医療・保育は月8〜14クリック）。

## 凍結期間

**2026-10 中旬まで、新規のデータ軸・ページ種別は投入しない。**

8/28〜9/5 に title 刷新・地図移設・保活余力・高齢化・財政・診断・都道府県ランキング・
道具送客・収益導線を一斉投入したため、これ以上足すと施策ごとの効果が分離できなくなる。
最初の測定窓は 9/11〜9/20（`npm run gsc:analyze -- --days 14 --since=2026-08-28` と
`--since=2026-09-06` の2窓）。

## 採用の3基準（すべて満たした軸だけ投入する）

1. **実 SERP の競合の厚み（実査）** — 想定クエリで実際に検索し、大手（不動産ポータル・
   東洋経済・総務省・LIFULL 等）が上位を支配していないこと。飽和市場での在庫競争は
   しない（例: 都道府県スコープの相場系・住みやすさ系は裏どり済みで拡張しない）。
2. **自サイト GSC での県スコープ需要の実在** — 「{県} {指標}」型のクエリが GSC に
   実際に出ていること。ゼロからの想像で軸を選ばない。
3. **データのカバレッジ率** — 集計対象の自治体が十分あり、県によっては数行しか無い
   薄い表を量産しないこと（例: 空き家率は 1,059/1,918 自治体で県別が薄くなる）。

## 判断の目安

- 過去実績ベースで、**新軸1本あたり投入1か月後 +100 クリック**が「伸びる軸」の基準。
  下回った軸は拡張せず、スコアの構成要素などページ内の文脈でのみ使う。
- 恒久的にやらないもの（レビュー§17）: 治安・学区・学力・騒音、条件 AND 組み合わせの
  静的ページ、年度別 URL の在庫増、都道府県ランキングの指標拡張、
  都道府県の「住みやすさ総合ランキング」（honesty 方針違反として却下済み）。
