# 家庭の備蓄チェック

ページ: `/bousai/stockpile`。初回版は広告なし。在宅備蓄の確認を支援し、持ち出し重量・地域の安全度・避難可否は判定しない。

## 算出・保存

- 人数は未選択で開始し、1〜20人。日数は7日を初期値に3日/7日。
- 飲料・調理用水の目安 = 人数 × 日数 × 3L。不足量は手持ちとの差の0以上、小数1桁で切り上げ（不足があれば最小0.1L）。2Lボトル換算は切り上げ。
- 食品・日用品は未確認/要準備/準備済みの自己確認。人数・日数変更時は確認状態を未確認に戻す。手持ちの水は維持。
- `kurashimap-stockpile-v1` に自動保存。形式・範囲・状態値を検証し、不正・将来形式は復元しない。初回表示では書き込まず、入力変更時に保存する。保存不可でも操作できる。リセットは画面で確認後に保存キーを削除し、削除失敗を明示する。
- コピー失敗時は代替テキストの折り畳みを開き、テキストにフォーカスして選択する。印刷は入力条件・水の目安/手持ちを静的な文字列で表示し、買い足し・未確認リストと出典を含む。操作フォーム・サイト共通ナビは除く。
- 根拠は `lib/stockpile.ts` に集約。確認日2026-10-24。水以外の数量を自動算出しない。期限通知・個別の商品提案・住所・アカウントは扱わない。

## GA4

|イベント|発火|
|---|---|
|stockpile_entry_view|ハザードページ/自治体災害カード内の入口が50%以上画面内に入った時、要素ごとに1回|
|stockpile_entry_click|入口クリック|
|stockpile_start|ページ表示中の初回入力（リセット後は再開扱い）|
|stockpile_conditions|人数/日数を変更|
|stockpile_inventory_update|手持ちの水や項目の状態を変更|
|stockpile_list_view|リストを初めて表示した時（リセット後は再計測）。表示済みでの連打は数えない|
|stockpile_copy|クリップボードへのコピー成功時|
|stockpile_print|印刷要求時。印刷完了・保存完了を意味しない|
|stockpile_reset|リセット実行|

全イベント: `measurement_version=2026-10-24`。入口は `placement=area/hazard-map`、操作は許可された `?from=` のみ `entry_placement=area/hazard-map/direct` として送信。リスト表示に `needed_count` と `unchecked_count` を付与。人数、日数、項目名、在庫、家族事情はGA4に送信しない。コピーは成功時、印刷は要求時の計測であることに注意。

探索では入口視認→クリック、入力開始→在庫更新→リスト表示→コピー/印刷を確認。イベント数の単純な比率を同一ユーザーのファネルとみなさず、ユーザー/セッション単位で分析。未登録なら `entry_placement` をイベントスコープのカスタムディメンションに登録する。GA4管理画面の変更はこのPRに含まない。

## 公開後

ハザードページ・自治体災害カードから利用できること、端末内復元、スマートフォンでの操作、GA4受信を本番で確認。少数の利用をもとに広告や機能を拡大せず、数週間の利用状況を確認する。
