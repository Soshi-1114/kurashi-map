# 地図の軽量化・地域比較・更新検知・教育データの拡張

## 配信と互換性

地図ブラウザは `manifest.json` と必要な分割ファイルだけを取得する。住民の初期表示は全指標列の計算に必要な表示年・1/5/10年前の4ファイル、地域を選ぶとその都道府県の年次履歴を追加取得する。学校・日本語指導はテーマを開いた際に対象年を取得する。学校の地域選択後は過年度も取得する。

62ファイルを内容ハッシュ付きURLで配信し、同じ画面での重複取得を抑える。失敗したリクエストは再試行でき、古いリクエストの完了で新しい選択を上書きしない。新規ファイルを先に書き、台帳を最後に更新する。取得中・失敗・未公表と0は区別する。

初期取得の非圧縮JSON合計は住民1,159,517バイト、学校149,829バイト。全体JSON3,788,662バイトに対して住民は69%減。これはコードとデータから算出したサイズであり、通信時間やCore Web Vitalsの改善率ではない。

`dataset.json` はサーバー生成・ランキング・既存ダウンロードとの互換性のため維持する。学校の過年度追加以外で住民・日本語指導の観測値は変更していない。既存の地図ページ・ランキング定義・広告配置は変更しない。

再生成例：

```sh
node scripts/build-foreign-resident-issues.mjs --cache-dir /path/to/cache
node scripts/build-foreign-issue-chunks.mjs
```

前者は既定の公開JSONへ出力すると分割ファイルと台帳も更新する。`--check` または別ファイルへの `--output` は公開分割データを変更しない。後者は既存JSONから分割ファイルだけを再生成する。処理中のクライアントのため旧ハッシュのファイルは残す。

## 最大3地域の比較

地図の下の比較欄で地域を検索するか、地域詳細の「この地域を比較に追加」を使う。住民・日本語指導は市区町村同士、学校基本調査は都道府県同士で比較する。指標ごとの値と原典を表示し、日本語指導は教育委員会の支援体制も確認できる。

`compareMunicipalities` と `comparePrefectures` のURLパラメータに候補を保存する。不明コード・重複は除去し、最大3件まで復元する。年度切り替えでも同じ地域を比較し、テーマ間の異なる統計単位を同じ表に混ぜない。

## 教育データの追加と制約

- 学校基本調査2023/2024/2025年度、47都道府県×小中×3年の282観測。原典の国公私立計を分子・分母ともに使用する。2023/2024年度の8表を追加し、原典URL・公表日・SHA-256を記録した。年選択、詳細の推移グラフ、複数県比較に対応する。ランキングの既定は引き続き2025年度。
- 2023年度の小学校：外国籍86,017人／在籍6,049,685人、中学校：32,449人／3,177,508人。2024年度の小学校：91,560人／5,941,733人、中学校：35,293人／3,141,132人。いずれも47都道府県の収録値を合計した検算値。
- [2023年度小学校](https://www.e-stat.go.jp/stat-search/files?cycle=0&layout=datalist&page=1&tclass1=000001212520&tclass2=000001212521&tclass3=000001212522&tclass4=000001212526&tclass5val=0&toukei=00400001&tstat=000001011528)、[2024年度小学校](https://www.e-stat.go.jp/stat-search/files?cycle=0&layout=datalist&page=1&tclass1=000001223980&tclass2=000001223998&tclass3=000001223999&tclass4=000001224003&tclass5val=0&toukei=00400001&tstat=000001011528)。中学校を含む全表の個別URLはJSONのsourcesを参照。
- 自治体資料は浜松市教育委員会の[事業説明資料](https://www.city.hamamatsu.shizuoka.jp/sogo/gaikokunitunagarukonosien/gaikokujin.html)を確認。2026年5月1日現在の公立小学校1,259人・中学校678人を、原典PDF5ページから別系列に収録した。分母が同資料にないため割合はnullとし、県別の国公私立計ランキングには統合しない。資料の国籍内訳・学校別人数や位置情報は収録しない。
- 自治体の公表資料が存在することと、全国の市区町村を同条件で比較できることは別。今回の調査では全国統一の自治体別在籍割合を追加できる資料は確認できず、推計・県別値の按分は行わない。日本語指導の必要人数は在籍人数の代わりにしない。

自治体の2観測は `data/foreign-resident-issues/local-education.json` で原典ハッシュとともに手動管理する。生成時に原典PDFのハッシュが変わっていれば停止し、人が数値・対象・基準日を再確認する。PDF自体は再配布せず、統計上の人数と出典を掲載する。e-Statと自治体資料の利用条件を一律のライセンスとして扱わない。

## 原典の週次照合とPR

`.github/workflows/foreign-issue-data-update.yml` は毎週月曜05:20 JSTと手動実行に対応する。既存の更新ワークフローとは独立する。

1. この自動更新の未マージPRがあれば、その実行はスキップする。更新ブランチは実行ごとに作り、過去のマージ方式やブランチの残存に依存しない。
2. 設定済みe-Statの表ID・公表日、全36原典の内容ハッシュを照合する。新しい表IDへの切り替えも検知する。住民・学校は次年度の公表候補を探すが、設定を自動変更しない。
3. 既存年度の住民・学校の改訂は候補JSONを再生成・検算する。自治体PDF・日本語指導の改訂は手動確認用のレポートのみを作り、古い確認値を新しい原典へ付け替えない。
4. 変更がある場合だけデータと検知レポートをドラフトPRにまとめる。新年度候補・手動確認事項が前回と同じなら時刻だけのPRは作らない。ネットワークや原典解析の失敗は「変更なし」とせずジョブを失敗させる。

読み取りだけの確認は `node scripts/check-foreign-issue-updates.mjs`。`--apply` を付けた場合のみ、検算した候補と `docs/data-updates/foreign-resident-issues.json` をローカルへ書き込む。新年度・定義・原典URLの確認後に設定を更新する。自動マージ・本番デプロイは行わない。

初回はマージ後にGitHub Actionsを手動実行し、リポジトリでActionsからのPR作成が許可されていることを確認する。GitHub側の権限設定はこの変更では操作しない。失敗時はActionsの実行結果を確認する。

## 検証

全体テスト1,037件、変更対象lint、型チェック、既存データ検証、ワークフローのYAML構文検証を実施。分割ファイルのハッシュ/件数、取得範囲と再利用、通信失敗後の再試行、比較の復元・削除・単位分離、教育推移、自治体の分母欠損、原典改訂と手動確認の分岐を確認した。

本番ビルドは3,156ページを生成して成功。ローカルの本番サーバーで地図・既存ランキング・自治体詳細・サイトマップと新規ランキング4ページのHTTP検証を通過した。PCの3自治体比較とSP幅375pxの表示を確認し、ページ全体の横はみ出しがないこと、学校テーマで全体JSONを取得せず学校の年度別ファイルだけを読むことを確認した。比較表はSPで横スクロールできる。確認用サーバーは停止済み。

実原典への更新検知を読み取りモードで実行した結果、改訂・新年度候補はともに0件だった。GitHub上のスケジュール実行・ドラフトPR自動作成は、ワークフローのマージ後に初回確認が必要。
