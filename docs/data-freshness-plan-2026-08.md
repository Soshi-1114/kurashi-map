## 2. 更新計画（時系列）

### ① 2026年8月末〜9月上旬: 待機児童（令和8年）

1. こども家庭庁の公表ページ（`/policies/hoiku/torimatome/r8`）で「（参考）資料1～6」Excel の URL を確認
   （末尾採番は年度で変わるため機械推測しない。docs/data-update.md §2 の検証手順で
   シート「資料６－１」「資料６－２」の存在を確認）。
2. `versions.mjs`: `CFA_XLSX_URL` を新 URL、`CFA_ASOF` を `"2026-04-01"` に更新。
3. `lib/rankings.ts`: `NEXT_UPDATE.waitlist` を令和9年（2027年4月1日時点）向け文言へ。
4. annual ワークフローを手動実行（まず `pref=saitama` で確認 → 全県）→ 自動作成される PR をマージ。

### ② 2026年9月: 国勢調査 確定値（人口等基本集計）

1. e-Stat で確定値の statsDataId を確認（速報集計とは別表。人口総数と、2020年比の
   人口増減率が算出できる表を選ぶ）。
2. `fetch-population-2025.mjs` の参照表を確定値へ切替（新スクリプトに改名する場合は
   **annual ワークフローの参照名も必ず更新**。過去にリネーム取り残しで失敗歴あり）。
3. `lib/rankings.ts`: `POPULATION_FRESHNESS` は「2025年国勢調査」のままでよいが、
   人口密度・人口増加率ランキングの note にある「**速報**」表記を「確定値」へ、
   `NEXT_UPDATE.population` を次回（2030年調査）向けへ更新。
4. 全県反映 → 人口比を実行時算出している外国人比率・人口密度も自動で確定値ベースになる。

### ③ 2026年9月下旬: 医療施設調査（令和7年）

1. e-Stat 統計コード 00450021 で令和7年調査の市区町村別 第1表（病院）/第2表（診療所・歯科）の
   **新しい statsDataId** を確認（毎年新表が追加される方式）。
2. `versions.mjs`: `MEDICAL_HOSP_STATSDATAID` / `MEDICAL_CLINIC_STATSDATAID` を差し替え、
   `MEDICAL_ASOF` を `"2025年10月"`、`AMENITIES_ASOF` の医療機関部分も同時更新
   （`tests/scripts/versions.test.ts` が同期を検査）。
3. annual ワークフロー手動実行（または①と公表が近ければまとめて1回）→ PR マージ。

### ④ 2026年9月末: 面積調（7/1 時点）

1. 国土地理院の面積調ページで 2026-07-01 時点の掲載を確認。CSV ファイル名が変わる場合は
   `MENCHO_URL` を差し替え（時点列追記のみなら URL 据え置き）。
2. `versions.mjs`: `MENCHO_ASOF` を `"2026-07-01"` へ。`fetch-area.mjs` を実行して反映。
   ※人口密度の分母のみで変動は微小。③と同じ PR にまとめてよい。

### ⑤ 2026年10月1日: quarterly（自動・対応不要）

災害リスク・保育が自動更新 → PR マージのみ。マージ後、reinfolib の直近報道発表で
XKT007（保育園・幼稚園）の原典年度が更新されていないか確認し、更新されていれば
`AMENITIES_ASOF` の「保育 令和N年度」を書き換える（2026-06-24 の更新は都市計画・
避難場所のみで保育の年度更新は確認できず。ラベル「令和5年度」が古い可能性もあるため
XKT007 レスポンスの元データ年度を一度実地確認するのが望ましい）。

### ⑥ 2026年12月中旬: 在留外国人（2026年6月末時点）

1. e-Stat（toukei=00250012）で 26-06-t2 の statInfId を確認し Excel を取得（手動運用。
   docs/data-update.md §7 の手順・全国総数の突合を実施）。
2. `FOREIGN_ASOF=2026-06` で `fetch-foreign-residents.mjs --all` → PR。

### ⑦ 2027年3月: 地価公示 2027 / ⑦' 2027年4月頃: S12・避難場所

- L01: `L01_VERSION: "27"` / `L01_ASOF: "2027"` へ（zip の存在確認後）。annual の
  定期実行（3/15）より公表が遅れる年があるため、公表確認後の手動実行が確実。
  `NEXT_UPDATE.landPrice` も更新。
- S12: 新年度版公開（例年4月）後に `S12_URL` / `S12_ASOF`、`AMENITIES_ASOF` の駅部分を更新。
- 避難場所: hinanmap の「全国データ」日付が 2026-06-19 から進んだら
  `GSI_SHELTER_ASOF`（必要なら URL）を更新（annual に取得ステップあり）。

## 3. 共通の注意点

- 各更新はデータ PR のマージ後に `deploy-preview.yml` で手動デプロイ → `indexnow.yml` 実行
  （docs/data-update.md §8）。
- 年度値の変更は **`versions.mjs` の1箇所のみ**（URL と ASOF は必ずセットで更新。
  整合性は CI の `versions.test.ts` が検査）。
- あわせて `lib/rankings.ts` の `NEXT_UPDATE`（次回更新予定の表示）を「反映済みの期の次」へ
  書き換えるのを忘れない。

## 4. 検討事項（計画外・任意）

- **都道府県地価調査（7/1 時点・9月公表）の併用**: 地価の鮮度を半年短縮できるが、
  地価公示との基準地差異の扱い（表示・出典の明確化）が必要な機能追加であり、本計画では対象外。
