# 外国人住民・教育環境・地域課題マップ：ローカルプロトタイプ

## 起動・画面

- URL: http://127.0.0.1:3140/map/foreign-resident-issues
- Node.js: package.jsonの対応範囲を使用（検証環境は22.22.2）。
- 起動: `npm run dev -- --hostname 127.0.0.1 --port 3140`。終了は起動ターミナルでCtrl+C。
- 住民増減の確認例: `/map/foreign-resident-issues?tab=residents&pref=saitama&code=11203&metric=rate5&year=2026`
- 教育環境の確認例: `/map/foreign-resident-issues?tab=education&stage=junior&code=11`
- 日本語指導の確認例: `/map/foreign-resident-issues?tab=guidance&pref=saitama&code=11203&stage=elementary`

## 実装済み

住民基本台帳2016～2026年の外国人住民数、同基準日の総人口による割合、1・5・10年増減数と増減率。学校基本調査2025年度の小中別・都道府県別外国籍人数と割合。文科省日本語指導調査2025年度の市町村所管公立小中学校の必要人数（外国籍・日本国籍別）、外国籍の指導実施人数、教育委員会の指導体制を表示する。

地図と連動する詳細、推移グラフ、代替数値表、指標別順位表、検索、地域・年度の選択、URL状態復元、取得失敗時の再試行、出典・基準日・公表日、SSR説明と初期集計、canonical・構造化データ・サイトマップ・共通導線を追加した。人数・割合は教育水準・治安・住みやすさスコアへ反映しない。

既存のMapView、HomeShell、地図レイヤー、フィルター、Municipality/Metric型、外国人住民比率計算、既存の自治体JSON・GeoJSON、RankingDefは変更しない。再利用は自治体コードと境界、県メタデータ、背景地図設定、サイト共通シェル・JSON-LDエスケープ。共通コードの変更はsiteNavの新規入口1件と、それに対応したテストの更新のみ。

新規地図は専用のMapLibreインスタンス、source/layer ID、React状態、CSS名前空間を持つ。既存ページの状態を共有しない。新しい順位表も専用データから計算する。静的な県別境界を選択時に読み、47県分の自治体境界を一括ロードしない。統計JSONは地図ライブラリと別に取得し、原典Excel/APIはブラウザから呼ばない。

指導の必要人数は外国籍在籍者数ではない。日本国籍の必要人数を別表示する。指導実施人数は「特別な配慮に基づく指導を受けている外国籍児童生徒」であり、「特別の教育課程」の人数と同一視しない。指導体制は問30の選択肢を短い説明へ加工し、その他の自由記述・個人情報・学校別情報は抽出しない。

住基の外国人住民と、出入国在留管理庁の中長期在留者・特別永住者等の統計は別系列。既存マップの在留外国人/国勢調査人口による比率を新ページの割合として再利用しない。学校は所在地、住民は登録地であり、そのまま一致する母集団ではない。

e-Statの[利用規約](https://www.e-stat.go.jp/terms-of-use)に沿って出典と加工主体を表示。ダウンロードURLは台帳の`downloadUrl`。xlsxの表形式が年度で異なるため、住基の結合セル・ヘッダ構造を検証して人口計列を抽出する。非常に横長の日本語指導ExcelはPython標準ライブラリでストリーム処理し、ふりがなを除外してコード・設問・学校種・人数単位を確認する。

### 欠損・比較

- 欠損はnull。0は原典で確認できた実数。北方領土6コードは対象外として明示。
- 政令市は親市の値、東京特別区は区の値を使用。行政区を重複加算しない。
- 過去にコードが違う自治体を名称一致で結合しない。比較に必要な基準年がない場合は増減を非表示。2016年以前の観測は収録せず、前年・5年・10年が不足する場合も同様。
- 県集計は構成する自治体のデータがすべてそろう場合のみ算出。率は人数合計/人口合計の加重集計。住基の最新年は全国総人口123,767,642人・外国人住民4,031,159人へ一致することを検算。
- 日本語指導の県表示は市町村所管校の合計。県所管校・国私立校は含まない。
- 増減率の基準人数が0の場合はnull、増減数は表示する。割合が同じ地域は同順位。順位は価値評価ではない。

## 更新手順

```sh
node scripts/build-foreign-resident-issues.mjs --download
```

キャッシュの既定はOSの一時ディレクトリ配下の `kurashi-foreign-resident-sources`。`--cache-dir` で変更できる。以前のMac用キャッシュを使う場合は `--cache-dir /private/tmp/kurashi-foreign-resident-sources` を指定する。原典ダウンロード後は `--download` なしで再生成可能。`--download` は不足ファイルだけを取得し、原典の改訂を確認するときは `--refresh` でキャッシュを再取得する。Node対応版とPython 3標準ライブラリ、既存xlsx依存を使用。既存データ更新スクリプト・ワークフローとは独立し、既存の自治体JSONを上書きしない。

対象年度・学校の一覧URL/表名・日本語指導の表ID/公表日は `scripts/config/foreign-resident-issues.json` で管理する。未確認の年度や表IDを推測して置換しない。更新時は原典の年度・母集団・表構造・公表日を確認して設定を変更する。`--config` でレビュー用の別設定も指定できる。住民の全国検算は設定した最終年で実施する。

```sh
# 公開JSONを変更せず、キャッシュから全系列の整形・検算を実行
node scripts/build-foreign-resident-issues.mjs --cache-dir /private/tmp/kurashi-foreign-resident-sources --check

# 更新候補を別ファイルへ出力し、既存データとの差分をレビュー
node scripts/build-foreign-resident-issues.mjs --cache-dir /private/tmp/kurashi-foreign-resident-sources --output /tmp/foreign-resident-issues-candidate.json
```

件数異常・重複観測・不明コード・負数・人数逆転・出典参照の欠落・設定と異なる年度・最終年の全国検算失敗は出力を止める。検証をすべて通過後に一時ファイルをrenameして置換する。`--check` は出力ファイルを作らない。UIの年選択・地図・詳細・グラフ軸・比較表・SSR説明は、住民/学校/日本語指導のそれぞれの収録年に追従する。学校の原典が新年度へ更新されても、未取得の日本語指導の年度まで更新したようには表示しない。

### Phase 3：犯罪・地域課題

[警察庁の犯罪オープンデータリンク集](https://www.npa.go.jp/toukei/seianki/hanzaiopendatalink.html)を入口に県警ごとのCSV、罪種、期間、位置粒度、修正履歴、利用・再配布条件を台帳化する。全国で同じ罪種・期間がそろわない場合は地域・対象犯罪を明示する。国籍情報のないデータは地域全体の犯罪として扱う。

追加が必要な実装は住所・コード正規化、位置精度の保持、集計と個別事案の分離、クラスタリング、ヒートマップ、カテゴリ・期間フィルター、原典付き詳細。事案レコードはid、自治体コード、カテゴリ、発生日/期間、公表日、一次資料URL、確認状況、行政対応・訂正履歴、位置精度を持つ。確認状況は公表・捜査・処分・判決等の事実を区別する。被害者・個人宅・未成年を特定できる精度は配信せず、安全に一般化できない事案は文章のみ。施設の宗教や外国人居住地域そのものを問題地点にしない。

### Phase 4：社会保障・行政対応・比較

[厚労省の国保資料](https://www.mhlw.go.jp/content/12401000/001670341.pdf)の外国人収納率は、把握可能な約150自治体の聞き取りで、基準時点も自治体により異なる。全国統一の自治体別系列として地図へ割り当てない。地方公式資料の収納額/賦課額/現年分・滞納繰越分・基準日を個別に記録する。

[被保護者調査関連資料](https://www.mhlw.go.jp/content/001684937.pdf)は「世帯主が外国籍の世帯」と外国籍の本人を区別する。世帯内に日本国籍者が含まれ得るため、外国人受給者数・受給率へ読み替えない。不正受給・不正請求、検挙・起訴・不起訴は各統計の対象と集計単位を確認し、外国人住民数を一律の分母にしない。

自治体の受入施策・制度変更は公式計画、担当部署、実施期間、対象、予算・実績、原典・更新日を持つ別データとして整理する。比較分析は同じ地域・期間・定義がそろう組だけを使い、対象件数・除外・計算式を表示する。相関から因果関係を断定せず、地域全体の犯罪と外国人住民数から外国人犯罪率を作らない。
